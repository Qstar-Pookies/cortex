title: Plan Before Edit
tags: example
---

Before you edit any file in this project:

1. Print the plan as a numbered list of files and the exact change to each.
2. Wait for me to say "go".
3. After editing, print a diff summary - files touched, lines added, lines removed.
4. Run the project's test command and paste the output verbatim.

Never edit a file you have not read this session. Never delete a file without printing it first.
